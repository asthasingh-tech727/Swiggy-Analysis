# Swiggy-Analysis
# Project Name/Headline: 🍴 Swiggy Sales Analysis

## 📌 Project Overview
This project analyzes **Swiggy food delivery sales data** to uncover insights into customer behavior, restaurant performance, and revenue trends.  
It uses **Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly)** for data cleaning, analysis, and visualization.

---

## 📊 Key Features
- **KPI Dashboard**:
  - Total Sales
  - Average Rating
  - Average Order Value
  - Ratings Count
  - Total Orders
- **Trend Analysis**:
  - Monthly Sales Trend
  - Daily Revenue Trend
- **Category Insights**:
  - Veg vs Non-Veg Revenue Contribution
- **Performance Metrics**:
  - Quarterly Performance Summary
  - Revenue by State
  - Top 5 Cities by Sales
